# T1574.002 - Space Pirates Sophos SafeStore DLL Side-Load

## Author
Trellix

## Description
This rule detects the Space Pirates secondary side-load chain: detects Sophos SafeStore binary `ssr64.exe` loading a rogue `safestore64.dll` from outside its genuine Sophos install location.

## Rule Class
File

## Rule TCL
```tcl
Rule {
    Process {
        Include OBJECT_NAME { -v "**\\ssr64.exe" }
    }
    Target {
        Match FILE {
            Include OBJECT_NAME { -v "**\\safestore64.dll" }
            Exclude OBJECT_NAME { -v "**\\Sophos\\**\\safestore64.dll" }
            Include -access "EXECUTE"
        }
    }
}
```

## Tested Platforms
OS: Win 10 x86 and Win 11 x86_64 ENS: 10.7.17 & 10.7.20

## Notes
Customers are advised to fine-tune the rule in their environment or disable the signature if there are false positives.
