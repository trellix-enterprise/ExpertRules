# T1552.001 - ePO Server Credential and Keystore File Access via Scripting Interpreters

## Author
Trellix

## Description
This rule detects `powershell.exe`, `powershell_ise.exe`, `pwsh.exe`, `cmd.exe`, `python.exe` and `python3.exe` reading or writing the ePO files `orion.keystore`, `db.properties`, `orion.ini` and `server.ini`, which hold ePO credentials and keys. It protects against ePO credential theft.

## Rule Class
File

## Rule TCL
```tcl
Rule {
	Process {
		Include OBJECT_NAME {
			-v "powershell.exe"
			-v "powershell_ise.exe"
			-v "pwsh.exe"
			-v "cmd.exe"
			-v "python.exe"
			-v "python3.exe"
		}
	}
	Target {
		Match FILE {
			Include OBJECT_NAME {
				-v "**\\McAfee\\ePolicy Orchestrator\\**\\orion.keystore"
				-v "**\\McAfee\\ePolicy Orchestrator\\**\\db.properties"
				-v "**\\McAfee\\ePolicy Orchestrator\\**\\orion.ini"
				-v "**\\McAfee\\ePolicy Orchestrator\\**\\server.ini"
			}
			Include -access "READ WRITE"
		}
	}
}
```

## Tested Platforms
OS: Win 10 x86 and Win 10 x86_64 ENS: 10.7.20

## Notes
Customers are advised to fine-tune the rule in their environment or disable the signature if there are false positives.
