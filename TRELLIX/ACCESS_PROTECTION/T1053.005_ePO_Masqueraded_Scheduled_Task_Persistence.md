# T1053.005 - ePO Intrusion Masqueraded Scheduled Task Persistence

## Author
Trellix

## Description
This rule detects any process creating or writing scheduled task files named `*SqlExpressTelemetrySync*`, `*SystemCertificatesSync*` or `*GoogleUserPEH*` in `%windir%\System32\Tasks\`. It protects against persistence through scheduled tasks disguised with legitimate-looking names.

## Rule Class
File

## Rule TCL
```tcl
Rule {
	Process {
		Include OBJECT_NAME { -v "**" }
	}
	Target {
		Match FILE {
			Include OBJECT_NAME {
				-v "%windir%\\System32\\Tasks\\*SqlExpressTelemetrySync*"
				-v "%windir%\\System32\\Tasks\\*SystemCertificatesSync*"
				-v "%windir%\\System32\\Tasks\\*GoogleUserPEH*"
			}
			Include -access "CREATE WRITE"
		}
	}
}
```

## Tested Platforms
OS: Win 10 x86 and Win 10 x86_64 ENS: 10.7.20

## Notes
Customers are advised to fine-tune the rule in their environment or disable the signature if there are false positives.
