# T1505.003 - Web Shell Suspicious Process Execution via Web Server


## Author
Trellix

## Description
This Rule Detects web server processes (Apache, Nginx, IIS, PHP-FPM, ColdFusion, Caddy)spawning commonly abused Windows binaries. This behavior is a strong indicator of web shell execution, where an attacker has uploaded or injected malicious server-side code and is issuing OS-level commands through the web server process.
 
## Rule Class 
Process

## Rule TCL
```tcl
Rule {
	Process {
			Include OBJECT_NAME { -v "httpd.exe" }
			Include OBJECT_NAME { -v "php-fpm.exe" }
			Include OBJECT_NAME { -v "php-cgi.exe" }
			Include OBJECT_NAME { -v "w3wp.exe" }
			Include OBJECT_NAME { -v "php.exe" }
			Include OBJECT_NAME { -v "apache*.exe" }
			Include OBJECT_NAME { -v "nginx.exe" }
			Include OBJECT_NAME { -v "coldfusion.exe" }
			Include OBJECT_NAME { -v "caddy.exe" }
	}
	Target {
		Match PROCESS {
			Include OBJECT_NAME { -v "hh.exe" }
			Include OBJECT_NAME { -v "cmd.exe" }
			Include OBJECT_NAME { -v "powershell.exe" }
			Include OBJECT_NAME { -v "rundll32.exe" }
			Include OBJECT_NAME { -v "regsvr32.exe" }
			Include OBJECT_NAME { -v "wscript.exe" }
			Include OBJECT_NAME { -v "cscript.exe" }
			Include OBJECT_NAME { -v "pwsh.exe" }
			Include OBJECT_NAME { -v "tasklist.exe" }
			Include OBJECT_NAME { -v "taskkill.exe" }
			Include OBJECT_NAME { -v "tskill.exe" }
			Include OBJECT_NAME { -v "sc.exe" }
			Include OBJECT_NAME { -v "reg.exe" }
			Include OBJECT_NAME { -v "netsh.exe" }
			Include OBJECT_NAME { -v "net.exe" }
			Include OBJECT_NAME { -v "net1.exe" }
			Include OBJECT_NAME { -v "csc.exe" }
			Include OBJECT_NAME { -v "whoami.exe" }
			Include OBJECT_NAME { -v "certutil.exe" }
			Include OBJECT_NAME { -v "curl.exe" }
			Include OBJECT_NAME { -v "bitsadmin.exe"}
			Include OBJECT_NAME { -v "schtasks.exe"}
			Include OBJECT_NAME { -v "mshta.exe"}
			Include OBJECT_NAME { -v "msiexec.exe"}
			Include OBJECT_NAME { -v "wmic.exe"}
			Include OBJECT_NAME { -v "hostname.exe"}
			Include OBJECT_NAME { -v "ipconfig.exe"}
			Include OBJECT_NAME { -v "nltest.exe"}
			Include OBJECT_NAME { -v "ntdsutil.exe"}
			Include OBJECT_NAME { -v "netstat.exe"}
			Include OBJECT_NAME { -v "ftp.exe"}
			Include OBJECT_NAME { -v "vssadmin.exe"}
			Include OBJECT_NAME { -v "installutil.exe" }
			Include -access "CREATE"
		}
	}
}

```


## Tested Platforms
OS: Windows 10 20H1 x86 and Windows 11 x64
ENS: 10.7.20 

## Notes
Customers are advised to fine-tune the rule in their environment or disable the signature if there are false positives.
