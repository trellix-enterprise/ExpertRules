# T1574.001 Space Pirates Public SearchOrder

## Author
Trellix

## Description
This expert rule  Detects any process attempting to execute C:\Users\Public\version.dll. The C:\Users\Public\ directory is world-writable, making it a common staging location for DLL hijacking and side-loading attacks. Legitimate software does not load version.dll from this path — execution here strongly indicates an attacker planted a malicious DLL to be loaded by a trusted process.

## Rule Class 
Files

## Rule TCL
```tcl

 Rule {
      Process {
          Include OBJECT_NAME { -v "**" }
      }
      Target {
          Match FILE {
              Include OBJECT_NAME { -v "C:\\Users\\Public\\version.dll" }
              Include -access "EXECUTE"
          }
      }
  }

```

## Tested Platforms
OS: Windows 10 20H1 x64 and x86
ENS: 10.7.18

## Notes
Customers are advised to fine-tune the rule in their environment or disable the signature if there are false positives.
