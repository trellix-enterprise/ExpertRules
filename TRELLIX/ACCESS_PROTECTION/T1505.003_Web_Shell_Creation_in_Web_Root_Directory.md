# T1505.003 - Web Shell Creation in Web Root Directory

## Author
Trellix

## Description
This Rule Detects web server processes (Apache, Nginx, IIS, PHP-FPM, PHP-CGI) creating or writing files directly into web-accessible directories (www, htdocs, wwwroot, nginx/html). This is a primary indicator of web shell deployment, where an attacker exploits a file upload vulnerability or remote code execution to drop a malicious script (PHP, ASPX, JSP) into the web root for persistent backdoor access.
 
## Rule Class 
File

## Rule TCL
```tcl
Rule {
	Process {
			Include OBJECT_NAME { -v "httpd.exe" }
			Include OBJECT_NAME { -v "php-fpm.exe" }
			Include OBJECT_NAME { -v "php-cgi.exe" }
			Include OBJECT_NAME { -v "w3wp.exe" }
			Include OBJECT_NAME { -v "apache*.exe" }
			Include OBJECT_NAME { -v "nginx.exe" }
			
	}
	Target {
		Match FILE {
			Include OBJECT_NAME { -v "**\\www\\**" }
			Include OBJECT_NAME { -v "**\\htdocs\\**" }
			Include OBJECT_NAME { -v "**\\wwwroot\\**" }
			Include OBJECT_NAME { -v "**\\nginx\\html\\**" }
			Include -access "CREATE WRITE"
		}
	}
}

```

## Tested Platforms
OS: Windows 10 20H1 x86 and Windows 11 x64
ENS: 10.7.20 

## Notes
Customers are advised to fine-tune the rule in their environment or disable the signature if there are false positives.
