# T1574.002 Space Pirates Logger SideLoad

## Author
Trellix

## Description
This expert rule Detects Logger.exe executing logexts.dll from any path outside the legitimate Windows Kits Debuggers directory. Logger.exe is a Microsoft Application Compatibility debugging tool that normally loads logexts.dll only from its SDK installation path (Windows Kits\...\Debuggers\). Loading logexts.dll from any other location indicates potential DLL search order hijacking, where an attacker plants a malicious logexts.dll to be side-loaded by this trusted binary (LOLBin abuse). Read access to logger.dat is also monitored to capture the full execution context of the tool.

## Rule Class 
Files

## Rule TCL
```tcl
 
Rule {
      Process {
          Include OBJECT_NAME { -v "\\Logger.exe" }
      }
      Target {
          Match FILE {
              Include OBJECT_NAME { -v "\\logexts.dll" }
              Exclude OBJECT_NAME { -v "\\Windows Kits\\\\Debuggers\\\\logexts.dll" }
              Include -access "EXECUTE"
          }
          Match FILE {
              Include OBJECT_NAME { -v "\\logger.dat" }
              Include -access "READ"
          }
      }
  }

```

## Tested Platforms
OS: Windows 10 20H1 x64 and x86
ENS: 10.7.18

## Notes
Customers are advised to fine-tune the rule in their environment or disable the signature if there are false positives.
