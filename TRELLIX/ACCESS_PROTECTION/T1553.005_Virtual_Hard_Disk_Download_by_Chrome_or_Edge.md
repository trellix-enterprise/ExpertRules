#  T1553.005 - Mark-of-the-Web Bypass - Virtual Hard Disk (.vhd) Download by Chrome or Edge

## Author
Trellix

## Description
Defends against disk-image smuggling that abuses the Mark-of-the-Web (MOTW) / SmartScreen Security Feature Bypass (MITRE T1553.005): detects Google Chrome or Microsoft Edge writing a .vhd container to disk, catching it before the image is mounted and its MOTW-evading payload can execute.

## Rule Class 
Files

## Rule TCL
```tcl
Rule {
		Process {
			Include OBJECT_NAME { -v "chrome.exe" }
			Include OBJECT_NAME { -v "msedge.exe" }
		}
		Target {
				Match FILE {
					Include OBJECT_NAME { -v "**.vhd" }
					Include -access "CREATE WRITE"
				}
		}
}
```

## Tested Platforms
OS: Win 10 (x86 and x86_64) ENS: 10.7.17

## Notes
Customers are advised to fine-tune the rule in their environment or disable the signature if there are false positives.
