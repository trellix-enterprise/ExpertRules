# T1036.005 - Space Pirates Windows Time Service Masquerade Persistence

## Author
Trellix

## Description
This rule detects persistence via DLLs masquerading as the Windows Time Service (`C:\ProgramData\Microsoft\Windows\bce32time.dll` and `C:\ProgramData\Microsoft\uuj32time.dll`). Matches both creation and execution so that DLLs already staged before this policy is deployed are still caught on load.

## Rule Class
File

## Rule TCL
```tcl
Rule {
    Process {
        Include OBJECT_NAME { -v "**" }
    }
    Target {
        Match FILE {
            Include OBJECT_NAME {
                -v "C:\\ProgramData\\Microsoft\\Windows\\bce32time.dll"
                -v "C:\\ProgramData\\Microsoft\\uuj32time.dll"
            }
            Include -access "CREATE WRITE EXECUTE"
        }
    }
}
```

## Tested Platforms
OS: Win 10 x86 and Win 11 x86_64 ENS: 10.7.17 & 10.7.20

## Notes
Customers are advised to fine-tune the rule in their environment or disable the signature if there are false positives.
